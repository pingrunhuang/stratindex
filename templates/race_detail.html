Strategy spec (exact JSON the engine ran)

{{ spec_pretty }}

Reproduce it

  1. Data: OKX public /api/v5/market/history-candles, {{ r.res.spec.symbol if r else '' }}, bar 4H, confirmed candles only, from 2022-01-01 (UTC) to the "data through" time above.
  2. Signals evaluated on each 4h close; orders fill at the next bar's open. Long-only spot, 100% of equity per trade, no leverage, no compounding tricks.
  3. Costs: {{ fee_note.split(' · ')[1] }} and {{ fee_note.split(' · ')[2] }}, applied on entry and exit.
  4. Stops: set at entry (ATR stop = fill − mult × ATR of the signal bar; % stop = fill × (1 − pct)). Triggered intrabar when low ≤ stop; filled at min(open, stop) minus slippage.
  5. Indicators: SMA/EMA (EMA seeded with SMA), Wilder RSI/ATR, Bollinger (population σ), Donchian = high/low of the previous N bars.
  6. Sharpe = mean(4h returns)/stdev × √2190 (rf = 0). OOS = last 182 days of the same run. Ranking: OOS Sharpe, ties → shallower OOS max DD.
  7. Or run our engine: python -m race run in the StratIndex repo (race/engine.py).
